Expense Tracker Web Application using Cloud Computing Services (Host/Store)

This Web Application leverages modern Cloud Computing services provided by AWS:

  • Cloud Hosting (Host): Deployed on an AWS EC2 (Elastic Compute Cloud) Linux instance running Python Flask and Gunicorn web application server.
  • Cloud Storage (Store): Managed relational database backend powered by Amazon RDS (Relational Database Service) running MySQL 8.0 for ACID compliance, secure credential isolation, and automated backups.

Note for Reviewers: On this GitHub Pages live preview, client-side persistence simulates direct AWS EC2 & Amazon RDS cloud sync with full CRUD features. Full production backend scripts, WSGI server configs, and RDS schema are included in the repository.

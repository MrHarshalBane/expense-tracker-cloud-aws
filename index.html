About This Cloud Deployment

This web application is built with Python Flask and designed for scalable production deployment on an AWS EC2 instance linked to a managed Amazon RDS MySQL database. When viewed on GitHub Pages, transactions are preserved in client storage with simulated RDS latency and real-time computation.
